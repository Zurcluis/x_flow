# Regras de Qualidade e Definition of Done

- Toda a entrega deve passar: `npm run lint`, `npm run typecheck`, `npm run test` e `npm run build`.
- Validação visual no browser com capturas em 1440px e 390px.
- Estados completos: loading, empty, error, success.
- Walkthrough detalhado no final de cada fase.
- Sem erros de hidratação ou consola.
