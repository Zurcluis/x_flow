# 3. Design System e Assets Canónicos

Data: 28 de agosto de 2026

## Contexto
O produto exige identidade visual premium, contemporânea, com dark mode refinado, tipografia elegante e símbolo linear oficial.

## Decisão
1. Adotar os tokens de design system definidos no Blueprint com base em Tailwind CSS e variáveis CSS.
2. Utilizar o logótipo em `assets/xflow-logo.svg.svg` como fonte canónica para todos os ecrãs.
3. Seguir rigorosamente a hierarquia visual do mockup `assets/references.png`.
